# RimStudio decision register

This register records 94 architecture decisions with status, rationale and evidence, rejected alternatives and consequences. It covers the whole stack: workspace and layering, the XML boundary, XPath and defs, scanning and caches, persistence and formats, datasets, Steam detection and the link farm, IPC, jobs, the frontend, testing, CI and packaging, security, logging, publishing, item math and Combat Extended (CE), the toolkit registry, licensing and naming, and the owner decisions of 2026-10-04 on the in house JSON database, the 0.1.0 scope, the vanilla default, Steam, signing and the licence (D-083 to D-088, section 13). Status values: decided (accepted, build on it), proposed (accepted for planning, needs a spike or a measurement), needs-owner (a human decision is required). Evidence links point to the [research notes](../research/rust-crate-research.md); the structure they justify is in the [architecture overview](overview.md), [workspace layout](workspace-layout.md) and [crate catalog](crate-catalog.md).

## 1. Resolution of the ten tensions

| Tension | Resolution | Decision |
|---|---|---|
| (a) `rimstudio-tauri-*` adapter plugins versus one command registry | One registry in `rimstudio-app`; wrappers, CLI routes, permission list and bindings are generated from it; no plugin crate per feature | D-005 |
| (b) Canonical crate names | `defs` (not `defdb`), `xpath`, `xml`, `steam` (VDF plus detection), `rules`, `sort`, `validate`, `library`, `workspace`, `datasets`, `design`, `ipc-types`, `app`, `shell` | D-004 |
| (c) Link farm location and `cfg(target_os)` | Planner, manifest and checks in `rimstudio-library::deploy` (portable code); link primitives behind `LinkBackend` implemented in `rimstudio-platform`, the only crate with OS `cfg` | D-009, D-010, D-039 |
| (d) CE calibration and patch generator | Logic in `rimstudio-design::ce` producing JSON node trees, orchestration in `toolkit::designer`, XML rendering only in `rimstudio-xml` | D-065 |
| (e) CLI crate versus shell | Separate package `rimstudio-cli` over `rimstudio-app`; no mutually exclusive features | D-007 |
| (f) Preact 10 versus 11 | Start on 10.29.8, write 11-clean code, test leg on 11, promote after a gate | D-050 |
| (g) ts-rs fallback versus tauri-specta rc | tauri-specta `=2.0.0-rc.25` primary with exact pins, ts-rs 12.0.1 documented and kept compatible | D-042 |
| (h) steamlocate | Dev-dependency of `rimstudio-steam` only, enforced by xtask | D-037 |
| (i) App identifier | Placeholder `app.rimstudio.desktop`, flagged for the owner | D-049 |
| (j) Cache key and location | Per file `(relative path, size, mtime ns, file id)` equality with FAT fallback; caches in the cache root, one manifest per library | D-023 |

## 4. Scanning, caches and persistence

| Id | Decision | Status | Rationale and evidence | Rejected alternatives | Consequences |
|---|---|---|---|---|---|
